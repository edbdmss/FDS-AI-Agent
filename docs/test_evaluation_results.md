## 해석과 한계

이 결과는 고정 모델로 평가한 PaySim 시간순 Test 성능으로 해석한다. 높은 성능은 앞선 제거 실험에서 확인한 거래 전 잔액 패턴 의존성과 함께 설명한다. 실제 금융 데이터에서 같은 성능을 보장한다고 해석하지 않는다.

현재 모델은 내부 학습 step 1–234로 학습하고 step 235–281로 튜닝한 모델을 그대로 사용한다. Test는 이번 실행에서 평가에 사용했으므로 이후 모델 수정에 이 결과를 참고하면 새로운 미관찰 평가 구간이 필요함을 명시한다. 과거 학습·선택 manifest의 `test_evaluated: false`는 당시 상태로 보존하고 이번 평가 manifest에 `test_evaluated: true`, `test_used_for_selection: false`를 기록한다.
